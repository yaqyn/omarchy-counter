# Counter artwork

Original vector cover: `cover.svg`, 1280 × 560. The count and F1 key illustrate one press adding one count; this is cover artwork, not a screenshot. `assets/panel.png` is the real panel captured in an isolated Omarchy session.

| Color | Role |
| --- | --- |
| `#101922` | Background and icon backing |
| `#edf3f7` | Primary text and digits |
| `#a8cbd7` | Primary accent and heading strokes |
| `#899da8` | Secondary cover text |
| `#263a46` | Frame and divider |
| `#14222c` | Counter face |
| `#1e3440` | Keycap |
| `#45616f` | Keycap edge |

Typography: DejaVu Sans for the wordmark and prose; DejaVu Sans Mono for the count and key. SVGs include system fallbacks. Cover background is explicit, so light/dark GitHub themes retain the same contrast.

Heading icons reuse the workspace canonical `readme-style/icons.json` geometry with 1.6-unit rounded strokes on a 24-unit grid. They are decorative and accompanied by text headings. These documentation colors do not override Omarchy's runtime theme tokens.
